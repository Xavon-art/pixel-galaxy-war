# Pixel Galaxy War 🚀

Made this in January 2025 just for fun. It's a classic arcade-style space shooter with a retro pixel-art vibe and fast-paced auto-fire action.

## 🎮 Instructions

![Keyboard](https://img.shields.io/badge/Controls-WASD-grey?style=for-the-badge&logo=keyboard&logoColor=white)
![Touch](https://img.shields.io/badge/Mobile-Touch-blue?style=for-the-badge&logo=touch&logoColor=white)

**On Computer:**
- Use **W, A, S, D** or **Arrow Keys** to move your ship.
- No need to press a key to shoot—the ship **fires automatically!**

**On Mobile/Tablet:**
- Use the on-screen **D-pad** buttons to navigate your ship.

**Rules:**
- Blast the red enemy ships to earn **10 points** each.
- You start with **3 lives**.
- You lose a life if you collide with an enemy or if an enemy reaches the bottom of the screen.
- Try to beat your **High Score** (saved locally)!

## 跑🏃‍♂️ How to Run

### 🛠️ Prerequisites

Since this is a pure Vanilla JS project, you don't need much:

![Git](https://img.shields.io/badge/git-%23F05033.svg?style=for-the-badge&logo=git&logoColor=white)
![VS Code](https://img.shields.io/badge/Visual%20Studio%20Code-0078d7.svg?style=for-the-badge&logo=visual-studio-code&logoColor=white)

### 💻 Local Setup

1.  **Clone the Repository**
    ```bash
    git clone https://github.com/Xavon-art/pixel-galaxy-war.git
    cd pixel-galaxy-war
    ```

2.  **Open the Project**
    Open the folder in VS Code.

3.  **Launch the Game**
    - You can simply double-click `index.html` to open it in your browser.
    - Or use the **Live Server** extension in VS Code for a better experience.

## 🌍 Deployment

The project is built with static files, making it perfect for free hosting!

![GitHub Pages](https://img.shields.io/badge/github%20pages-%23121013.svg?style=for-the-badge&logo=github&logoColor=white)
![Vercel](https://img.shields.io/badge/vercel-%23000000.svg?style=for-the-badge&logo=vercel&logoColor=white)

1.  Push your code to your GitHub repository.
2.  Go to **Settings** > **Pages**.
3.  Set the Source to the `main` branch.
4.  Your game will be live at `https://your-username.github.io/pixel-galaxy-war/`.

## 💡 The Idea

I wanted to capture the frantic energy of old-school arcade cabinets like *Galaga*. By removing the manual fire button and making the ship auto-shoot, the game becomes a test of pure reflexes and positioning. It’s all about dodging and survival.
